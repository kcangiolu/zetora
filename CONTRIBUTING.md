# Contributing

Thanks for your interest in Zetora.

## Issues are welcome, pull requests are not accepted yet

Bug reports, questions and feature ideas are very welcome: open an [issue](../../issues).

Code contributions are not accepted for now, so pull requests will be closed without review. This keeps the project under a single rights holder while its licensing is being settled. The policy will be revisited, and this file updated, when that changes.

## Reporting a bug

A good report includes:

- what you did, what you expected, and what happened instead;
- how Zetora is running: `pnpm dev`, or the Docker Compose stack and which profiles are enabled;
- which AI provider and model were involved, if any;
- relevant server logs or browser console errors, with API keys, emails and other secrets removed.

For a security problem, do not open an issue: follow [SECURITY.md](SECURITY.md).

## Suggesting a feature

Describe the problem you want solved before the solution you have in mind: it leaves room for the approach that fits Zetora best.
